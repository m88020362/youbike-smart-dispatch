# YouBike 預測式供需調度系統

本專案以新北市 YouBike 站點為研究對象，利用 AWS SageMaker 與 LightGBM 預測站點未來 30 分鐘與 60 分鐘的車輛占比，提前辨識空車與滿車風險。

系統不只提供預測，也將結果轉換成兩種可執行的介入方式：

1. 使用者端：透過「友愛接力」回饋機制，引導原本就在附近移動的使用者稍微改變借車或還車站點。
2. 營運端：依據未來 30 分鐘與 60 分鐘的風險，協助營運人員找出需要優先關注的站點。

核心概念是：

> 不等站點真的空車或滿車才處理，而是在問題發生前先預測，並優先利用低成本的使用者協作；若風險持續存在，再交由營運端進一步調度。

---

## 問題背景

YouBike 站點的供需失衡具有明顯的時間與空間差異。

同一個站點可能在通勤尖峰快速被借空，也可能因大量使用者集中還車而接近滿站。對營運單位而言，短暫的失衡不一定值得立刻派車，但如果 30 分鐘後與 60 分鐘後都維持高風險，就更值得優先處理。

因此，本專案關注的不是單純回答：

> 「這個站會不會缺車？」

而是進一步回答：

> 「這個站未來的供需狀況會怎麼變化？這個問題是短暫的，還是可能持續？」

---
